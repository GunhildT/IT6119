# IT6119
Final project - Risikoklassifisering ved intracerebral blødning
Inneholder mitt avsluttende prosjekt i emnet IT6119: Helsedata/KI ved NTNU

Problemstilling: 

Kan en enkel logistisk regresjonsfmodell basert på alder, Glasgow Coma Scale (GCS), hematomvolum og intraventrikulær blødning (IVH) brukes til å klassifisere risiko for mortalitet under sykehusoppholdet hos pasienter med intracerebral blødning?

Datasettet: 

Prosjektet bruker et offentlig tilgjengelig og anonymisert datasett med pasienter med intracerebral blødning. Originaldatasettet er tilgjengelig på Zenedo: 
https://doi.org/10.5281/zenodo.15368709
Innhold i GitHub

IT6119_ICH_analysis.ipynb: Jupyter-notatbok med dataklargjøring, deskriptive analyser, logistisk regresjon, modelltrening og evaluering.

README.md: Informasjon om prosjektet, problemstillingen og innholdet i repositoriet.

.gitignore: Angir hvilke lokale datafiler og midlertidige filer som ikke skal inkluderes i Git.
